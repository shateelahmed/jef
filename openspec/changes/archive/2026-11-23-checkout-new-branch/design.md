## Context
jef commands are plain bash (3.2 on macOS) and iterate first-level repos via lib/repos.sh. lib/confirm.sh is the only interactive code today; tests drive it through `run_tty` (script(1)).

## Decisions
- **Syntax** mirrors git: `-b/--new` is a boolean flag that switches checkout into create mode, with positionals `<new_branch> <base>` (exactly two). Without `-b` exactly one positional, as now.
- **Base resolution** per repository: `git rev-parse --verify --quiet "<base>^{commit}"`, so `main`, `origin/main`, a tag or a SHA all work. When `<base>` does not resolve but `origin/<base>` does (a branch that only exists on the remote), that is used for the repository and reported as "Created from origin/<base> and checked out". The branch is created with `git checkout -b <new> <base>` and `--no-track`, so a remote base such as `origin/main` never becomes the new branch's upstream (pushes would otherwise target the base).
- **Eligibility** is computed before picking: a repository is unavailable when `refs/heads/<new>` exists ("branch exists") or `<base>` resolves neither locally nor as `origin/<base>` ("no <base>"). Unavailable repos are drawn dimmed with the reason and the cursor skips them for toggling (Space is a no-op on them). The cursor starts on the first available row. If no repository is available the picker is skipped: the reasons are listed, "No repository can get <new_branch>. Nothing was created." is printed and the command exits 1.
- **Picker (lib/select.sh)**: `select_repos` takes parallel arrays of labels and disabled-reasons, draws on /dev/tty (stderr fallback is not needed: it only runs when stdin and stdout are terminals), reads one key at a time with `IFS= read -rsn1` from /dev/tty, decodes ESC [ A/B arrows by reading two more characters, redraws in place with ANSI cursor-up (`\033[<n>A`) and clear-line (`\033[2K`), hides/shows the cursor and restores it via a trap on exit/INT. Terminal echo is switched off with `stty -echo` (saved with `stty -g`, restored with the cursor) so keys typed during a redraw are not echoed. Result: a `selected_indexes` array. Enter with nothing ticked or q/Esc cancels → "Aborted. Nothing was created." exit 1. No `tput`, `mapfile`, `read -t <fraction>` or associative arrays (bash 3.2).
- **No terminal**: if `-m` is given, it selects by repository directory name (unknown names → exit 2 listing them, as `jef merged -m` does); ticked-but-unavailable named repos are reported and skipped. Without `-m` and without a terminal: "Not running in a terminal. Re-run with --repo to choose repositories. Nothing was created." exit 2. With `-m` on a terminal the picker is not shown.
- **Output**: header lines "Target directory", "New branch", "Base"; per selected repo the usual "Working directory <name>" header then "Created and checked out" or "Could not create" (failed). Unselected repos are not counted; unavailable named repos count as skipped. Summary via finish_run (exit 3 on failure).

## Risks
- Terminal handling differences: keep to plain ANSI sequences and `read -rsn1` (`stty` only to turn echo off and restore it).
- Tests: the existing run_tty waits for "[y/N]" and sends a line; a generalised helper must wait for a picker marker and send raw keys.
